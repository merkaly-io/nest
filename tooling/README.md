# @merkaly/nest-tooling

Dev tooling compartilhado dos apps NestJS da Merkaly: ESLint 9 (flat config), Prettier, tsconfig base/build, Nest CLI, TypeScript, ts-node.

Instale como **devDependency única** e estenda as configs. Guia completo no README do repositório: https://github.com/merkaly-io/nest
